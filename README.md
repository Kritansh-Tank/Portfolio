# Portfolio Website

🚀 Live Demo: [kritansh-tank.github.io/Portfolio](https://kritansh-tank.github.io/Portfolio/)

This is my portfolio website built to serve as an **online resume** and showcase my **skills**, **projects**, and **contact information** in a visually appealing and responsive format.

---

## 📌 Features

- **About Section**  
  A concise introduction about me, my background, and career aspirations.

- **Skills**  
  Highlighted technical and non-technical skills, including frameworks, tools, and soft skills.

- **Projects**  
  A curated list of my top projects with brief descriptions, tech stacks used, and live/demo links where available.

- **Contact Form**  
  A fully functional contact form allowing visitors to reach out to me directly.

- **Responsive Design**  
  Optimized for all screen sizes — mobile, tablet, and desktop.

---

## 🛠 Tech Stack

- **Next.js** – React framework for building fast, user-friendly apps.
- **TypeScript** – Type-safe code for better developer experience.
- **Tailwind CSS** – Utility-first CSS framework for rapid UI development.
- **Framer Motion** – Smooth animations and transitions for an enhanced user experience.
